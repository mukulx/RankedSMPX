# Support

Before asking for help, check the [FAQ](faq.md), [installation guide](installation.md), and [configuration map](configuration.md). Confirm the server is running Java 21+ and a supported Paper or Folia version.

## Get help

- [Discord support server](https://discord.gg/QGsJYht2vy) for setup questions and discussion.
- [GitHub issues](https://github.com/mukulx/RankedSMP/issues) for reproducible bugs and feature requests.
- [Modrinth](https://modrinth.com/plugin/rankedsmpx) for plugin downloads.

## Report a bug

Include:

- RankedSMPX version (current source: 3.0.0)
- Server software and exact Minecraft version
- Java version
- Steps to reproduce and what you expected to happen
- Relevant console log or `latest.log` excerpt
- The affected config section, with secrets removed

Do not post Discord bot tokens, database passwords, or other credentials. For a Discord issue, redact `bot.token` before sharing any config.
